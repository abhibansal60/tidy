# Tidy brand kit

Tidy is a little envelope with a broom, a "0" unread badge and sparkles: inbox zero, safely.
Free to use in posts, videos and slides about Tidy (MIT, like the code). SVGs scale to any size.

| File | Use |
|---|---|
| `tidy-mascot.svg` / `.png` | the character on a transparent background (videos, stickers, overlays) |
| `tidy-icon.svg` / `.png` | square app icon or avatar |
| `tidy-lockup-light` / `-dark` | mascot plus "tidy" wordmark, for headers and title cards |
| `tidy-launch-card` | 16:9 image for X and LinkedIn posts |

Colors: mint `#3DDC97`, ink `#0E2A20`, night `#0F1A16`, sparkle `#F4C542`, badge `#FF5C5C`, blush `#FF8FA3`. Font: Inter.
